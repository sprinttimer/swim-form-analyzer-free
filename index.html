プールサイドから撮影したクロール動画を、端末内のPose推定と時系列解析で評価します。自動解析後にイベント時刻や関節点を手動補正でき、補正履歴は次回以降の個人キャリブレーションに利用されます。

🔒 解析対象の動画は外部サーバーへ送信しません。 映像フレームはブラウザ内で解析します。初回起動時にはMediaPipeのプログラム／モデル取得のため通信が発生します。MediaPipe自体の利用統計に関する扱いは提供元のプライバシー仕様に従います。完全オフライン運用にする場合は、JS・WASM・モデルを同一サーバー／アプリ内へ同梱してください。

1. 撮影方法 — 精度を優先する標準条件

✓ 定点撮影撮影者が歩いて追わず、スマートフォンを固定します。カメラ移動はフォーム変位と混ざるため、Ver.1では定点を標準とします。
✓ 真横から泳者の進行方向に対してできるだけ90°。斜め前・斜め後ろ・見下ろしを避けます。
✓ レンズは水面＋30〜60cm目安水面ギリギリではなく、背中を大きく見下ろさない低い側面位置。スマートフォンは水平にします。
✓ 60fps推奨30fpsでも解析できますが、入水時刻などの時間分解能を優先する場合は60fps撮影を推奨します。
✓ 近いレーン・ズームなし可能ならカメラに近いレーン。泳者が画面幅のおよそ35〜70%を占める距離を目安にします。
✓ 中央を通過する3〜8秒を解析25m全体を無理に追わず、中央付近で姿勢が明瞭な数ストロークを選びます。
✓ 「泳者位置の水面」を指定プールサイド手前の水際ではありません。泳いでいる人の胸〜腰付近を横切って見える水面を、画面上の2点で指定します。
✕ 高い位置から見下ろす2D側面解析では投影誤差が増えます。胸～顔の高さから下向きに撮る方法は非推奨です。
△ 歩きながら追従この版では背景移動を推定して追従補正します。ただし手ブレ・ズーム・上下動が増えるため、精度優先なら定点撮影を推奨します。
